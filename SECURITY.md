# Security Policy

## Reporting a Vulnerability

Remedi processes simulated patient income data and public OpenFDA records. We take data security and privacy seriously.

If you discover a security vulnerability or sensitive data exposure risk, please report it responsibly:

- Email the maintainer directly via GitHub profile contact.
- Do not open a public issue for sensitive security vulnerabilities.
- We will acknowledge receipt within 48 hours and work on a fix promptly.
